# 🏁 Projeto Speedrun — Prova HTML

Este projeto foi desenvolvido como parte de uma atividade acadêmica de **HTML**, com o objetivo de colocar em prática os principais recursos da linguagem de marcação.

O site tem como tema **Speedrun**, prática em que jogadores tentam completar jogos ou objetivos específicos no menor tempo possível.

## 📖 Sobre o projeto

O projeto apresenta informações relacionadas ao universo das speedruns, abordando assuntos como:

- O que é Speedrun;
- História das Speedruns;
- Categorias de Speedrun;
- Recordes;
- Jogos populares nesse meio;
- Conteúdos em áudio, vídeo e imagens;
- Formulários e elementos interativos fornecidos pelo próprio HTML.

O objetivo principal é demonstrar conhecimentos em **HTML e HTML5**, utilizando uma estrutura organizada e elementos semânticos.

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5**
- Git
- GitHub
- Visual Studio Code

O foco do projeto é a construção e estruturação das páginas utilizando HTML.

## 📂 Estrutura do projeto

O repositório está organizado da seguinte maneira:

```text
Prova-HTML/
│
├── audio/
│   └── Arquivos de áudio utilizados no site
│
├── html/
│   └── Páginas HTML do projeto
│
├── img/
│   └── Imagens utilizadas nas páginas
│
└── video/
    └── Arquivos de vídeo utilizados no site
```

## 🧩 Recursos utilizados

Durante o desenvolvimento foram utilizados diferentes recursos do HTML5, como:

- Estrutura semântica com `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` e `<footer>`;
- Navegação entre diferentes páginas;
- Tabelas;
- Formulários;
- Campos como `date`, `file` e `range`;
- `<datalist>`;
- `<details>` e `<summary>`;
- `<figure>` e `<figcaption>`;
- Áudio;
- Vídeo;
- Imagens;
- `<abbr>`;
- `<mark>`;
- `<del>` e `<ins>`;
- `<blockquote>` e `<cite>`;
- `<progress>` e `<meter>`;
- Uso de `<time>` para representação de datas.

## 🎯 Objetivo

O objetivo deste trabalho é praticar os conceitos estudados durante as aulas de HTML, desenvolvendo um site com múltiplas páginas, navegação e diferentes elementos da linguagem.

Além disso, o projeto busca demonstrar a utilização correta da **semântica HTML**, organização de arquivos e incorporação de conteúdos multimídia.

Durante o desenvolvimento deste projeto foram praticados conceitos como:

- Organização de um projeto web;
- Criação de múltiplas páginas HTML;
- Navegação utilizando links;
- HTML semântico;
- Criação de tabelas;
- Criação de formulários;
- Inserção de imagens;
- Reprodução de áudio e vídeo;
- Utilização de elementos avançados do HTML5;
- Organização de arquivos em diferentes diretórios;
- Versionamento utilizando Git e GitHub.
